### Descripción del Proyecto
Desarrollo de una API REST completa para gestionar usuarios, eventos y categorías, utilizando **Node.js**, **Express**, **MongoDB** como base de datos NoSQL y **Mongoose** como ODM. El proyecto integra autenticación y autorización mediante JWT y cookies seguras, validaciones robustas con express-validator, relaciones embebidas y referenciadas, virtual populate y operaciones CRUD con eliminación lógica y en cascada.
